# Project instructions

Do not inspect these directories unless explicitly asked:

- .venv/
- venv/
- node_modules/
- target/
- tmp/
- temp/
- data/
- dist/
- build/
- docs/
- .cache/

For repository analysis, first inspect:
- README.md
- Cargo.toml
- src/

Prefer grep/find over reading large files.
Do not read generated datasets, logs, dumps, virtualenvs or dependency directories.
Code, comments, docstrings in English.
